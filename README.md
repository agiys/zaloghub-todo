# Список задач (ZalogHub, тестовое задание)

React + TypeScript + Vite. Добавление, отметка выполненной, удаление, фильтры (все / активные / выполненные), хранение в localStorage. Пустые и состоящие из пробелов задачи добавить нельзя.

## Запуск

```bash
npm install
npm run dev     # http://localhost:5173
npm run build   # production-сборка
```

## Время выполнения

Около 30 минут.
